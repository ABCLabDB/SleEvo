## RNA-seq normalization and phenotype-specific expression matrices

Gene-level read counts generated by featureCounts were normalized
using DESeq2 and converted to FPKM values.

### Normalization procedure

For each species:

1. A DESeq2 dataset was constructed:

   dds <- DESeqDataSetFromMatrix(
       countData = raw_counts,
       colData   = sample_metadata,
       design    = ~ 1
   )

2. Size-factor normalization was performed:

   dds <- DESeq(dds)

3. Gene length information (basepairs) was assigned:

   mcols(dds)$basepairs <- gene_length_vector

4. FPKM values were calculated:

   fpkm_matrix <- fpkm(dds)

5. Expression values were log2-transformed:

   log2(FPKM + 1)

Species-specific FPKM matrices were merged into
phenotype-specific expression matrices.
