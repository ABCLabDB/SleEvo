## Metadata

Processed metadata files are not included in this repository.

To reproduce the analysis, place:

- species_sleep_metadata.txt

under the following directory:

data/Result1/


## External FASTA data

This analysis requires MUSCLE-aligned CDS FASTA files.

Expected directory:

data/Fasta/

File naming format:

[GENE]_muscle.fasta

Each FASTA file contains CDS alignments across species.
These files were generated using a custom ortholog selection
and MUSCLE alignment pipeline and are provided in this repository.
